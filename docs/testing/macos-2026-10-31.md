构建仍输出既有的 ts-rs 属性解析警告和 Vite 大包提示。`npm ci` 报告 6 个依赖漏洞（4 low、1 moderate、1 high）；本次没有升级依赖。

## macOS 原生验证

通过 `KNOWWISE_DATA_DIR`、`KNOWWISE_CONFIG_DIR` 指向临时目录运行实际 Tauri 应用，合成样本放在含中文和空格的路径中。

- 新建空库可启动，任务中心显示 0 个任务。
- `Command+O` 可打开 macOS 原生文件选择框。
- PDF、Markdown、DOCX 均可导入、阅读并完成本地索引。
- `Command+F` 可打开搜索；Markdown 中文关键词“狐狸”找到预期的 8 处命中。
- PDF 页面画布在正常桌面激活后可显示。
- 快速笔记可以保存，重启应用后仍能查询和显示原内容。
- 使用真实 `SystemSecretStore` 验证 macOS Keychain：不存在的条目、写入、读取、覆盖、删除、重复删除、删除后查询均符合预期。只使用随机账户名和合成凭据，测试条目已删除。

后台启动的 WKWebView 曾显示 `document.visibilityState = hidden`，搜索动画停在起始透明度 0。通过 Finder 激活后显示恢复；此现象未作为产品布局缺陷修正。用于定位的页面标题诊断和临时浏览器样例已从源代码移除。

界面出现其他操作后停止自动驱动，保留当前窗口和测试数据。该窗口使用临时测试库；退出后直接打开应用会使用正常的应用数据目录。

## 离线翻译

在隔离目录安装并校验中英双向模型和 macOS arm64 ONNX Runtime 1.23.2；`install-models.mjs --check` 验证两个模型及运行库均通过。实际加载 Rust ONNX 后端执行，未配置远端模型。

| 方向 | 输入 | 实际输出 | 置信度 |
| --- | --- | --- | --- |
| 中 → 英 | 你好，世界。 | Hello, world. | 0.7434 |
| 中 → 英 | 这是用于测试的中文句子。 | This is the Chinese sentence for testing. | 0.6833 |
| 英 → 中 | Hello, world. | 你好,世界之王,你们好 | 0.3276 |
| 英 → 中 | This is a test sentence. | 这是一次试验判决 | 0.3864 |

双向后端均可运行；英译中两条样例有明显语义偏差，不能视为翻译质量验收通过。建议后续单独评估该方向的模型与解码质量。

首次模型下载发生 TLS 连接重置。本机系统代理为 `127.0.0.1:7897`，为下载进程显式设置 `HTTPS_PROXY`、`HTTP_PROXY` 和 `NODE_USE_ENV_PROXY=1` 后下载成功；没有修改系统代理配置。此环境使用 Node.js 26，不代表旧版 Node 支持相同代理开关。
